# restaurant_menu

A simple Flutter Restaurant Menu app (TMA3084 Lab).

## Description
Single-screen menu showing three food `Card` widgets (Salmon Sushi, Tamago Sushi,
Spicy Tuna Sushi). Tapping a card opens a detail screen for that food.

## Setup / How to run
1. Install the Flutter SDK and run `flutter doctor`.
2. `flutter pub get`
3. `flutter run` (choose Chrome, Windows or an Android device)
